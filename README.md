# TinyArtist 🎨

A simple and lightweight mobile painting app built with **Flutter**, designed to let users unleash their creativity on the go.

## About
TinyArtist provides an intuitive digital canvas where users can sketch, paint, and create artwork directly on their mobile device — no complicated tools, just a clean and fun drawing experience.

## Features
- Freehand drawing/painting canvas
- Multiple brush sizes and colors
- Undo/redo functionality
- Save and export artwork
- Simple, distraction-free UI
- Cross-platform (Android & iOS) via Flutter

## Tech Stack
- **Framework**: Flutter
- **Language**: Dart
- **Platform**: Android / iOS

## How It Works
Users open the app, pick a color and brush size, and start painting on the canvas. Artwork can be saved to the device gallery for sharing or keeping.

## Future Improvements
